# پل ArenaAgentBridge

**یک پل محلی و سازگار با OpenAI که فریمورکهای ایجنت (Hermes، OpenClaw، LiteLLM،
Open WebUI یا حتی `curl`) را به رابط وب [Arena.ai](https://arena.ai) وصل میکند —
از طریق یک نشست مرورگر واقعی که خودتان قبلاً وارد آن شدهاید.**

بدون API رسمی. بدون توکن reCAPTCHA. بدون ذخیرهٔ کوکی. بدون دور زدن کپچا. فقط یک
مرورگر واقعی که همان کاری را میکند که همیشه میکند، بهعلاوهٔ یک سرور FastAPI و یک
کدبیس افزونه برای **کروم/اج** و **فایرفاکس**.

[English README](README.md) · [مستندات پروتکل](docs/PROTOCOL.fa.md) · [عیبیابی](docs/TROUBLESHOOTING.fa.md) · [فایرفاکس](docs/FIREFOX.fa.md) · [اتصال ایجنتها](docs/HERMES_OPENCLAW.fa.md)

> ⚠️ **اول این را بخوانید.** خودکارسازی سایت به این شکل احتمالاً ناقض شرایط استفادهٔ
> Arena.ai است و ممکن است به محدود یا مسدود شدن حساب منجر شود. این پروژه «دور زدن»
> نیست: از نشست خودِ شما و روی رایانهٔ خودتان استفاده میکند. مسئولیت با خودتان است و
> فقط برای مصارف شخصی و آزمایشی. بخش [هشدار حقوقی](#هشدار-حقوقی-و-ایمنی) را ببینید.

## این پروژه در یک نگاه

| موضوع | مقدار |
| --- | --- |
| نسخه | `1.3.0` |
| زبانها | Python 3.10+ (سرور)، JavaScript ES2020 (افزونه) |
| سرور | FastAPI + uvicorn روی `127.0.0.1:8000` |
| مرورگرها | Chrome/Edge 111+ و Firefox 128+ (Manifest V3) |
| مسیر اصلی | `POST /v1/chat/completions` (سازگار با OpenAI) |
| مدلها | `arena-agent` و `arena-agent-direct` |
| ترافیک | فقط لوکالهاست؛ هیچ دادهای بیرون از سیستم نمیرود |
| تستها | ۱۶۳ تست پایتون + ۲۰۰ چک jsdom — بدون نیاز به مرورگر |

## چرا این پروژه؟

بعضی ابزارها و ایجنتهای محلی فقط با «OpenAI-compatible endpoint» کار میکنند، ولی
دسترسی رسمی به مدل پشت سایت ندارید. این پروژه آن شکاف را با سه جزء پر میکند:

1. سرور FastAPI درخواستهای استاندارد OpenAI را میگیرد.
2. افزونهٔ مرورگر همان درخواست را در تب بازِ سایت تایپ میکند و روی دکمهٔ ارسال کلیک میکند.
3. پاسخ از DOM خوانده، تمیز و ایمنسازی میشود و به فرمت `chat.completion` برمیگردد.

کاربردهای واقعی: وصل کردن Hermes/OpenClaw به مدل پشت سایت، تست سریع پرامپتها از
طریق `curl`، یکسانسازی چند ابزار روی یک درگاه، و استفاده از نشست لاگینشده بدون
دستکاری کوکی یا توکن.

## معماری

```
Hermes / OpenClaw / curl
        │  درخواست سازگار با OpenAI  (HTTP → 127.0.0.1:8000/v1)
        ▼
   سرور FastAPI ── صف (تکدرخواستی) ──▶ WebSocket  /ws/browser
        │                                      │
        │                                      ▼
        │                        افزونهٔ مرورگر (content script)
        │                                      │  خودکارسازی DOM: تایپ، کلیک، خواندن
        │                                      ▼
        └──────────────◀──────────     https://arena.ai/agent
```

**جریان یک درخواست، مرحلهبهمرحله:**

1. ایجنت یک `POST /v1/chat/completions` میفرستد.
2. سرور آرایهٔ `messages` را به یک «متن واحد با برچسب نقشها» تبدیل میکند
   (حالت `agent` یک مقدمهٔ کوتاه اضافه میکند؛ حالت `direct` متن خام را میگذارد).
3. درخواست داخل صف قرار میگیرد — **هر بار فقط یک درخواست** به مرورگر میرود، چون
   رابط سایت همزمان فقط یک پرامپت را جواب میدهد.
4. افزونه پرامپت را با متد native setter و رویداد `input` (همان چیزی که React
   انتظار دارد) داخل کادر متن میگذارد و روی **Send** کلیک میکند.
5. افزونه همزمان DOM و **بستههای استریم خودِ سایت** (`a0:` متن اصلی، `ag:`
   استدلال، `ad:` دادهٔ اضافه) را رصد میکند تا لحظهٔ شروع و پایان تولید پاسخ را
   دقیق تشخیص دهد.
6. پاسخ به سرور برمیگردد، از فیلتر دستورهای مخرب عبور میکند و بهصورت
   `chat.completion` (یا جریان SSE) تحویل داده میشود.

خطاها صریحاند، نه خاموش: `captcha_required`، `login_required`، `dom_changed`،
`page_timeout`، `browser_offline`، `queue_full` و… هر کدام کد HTTP مشخص و بدنهٔ خطای
بهسبک OpenAI دارند.

## اجزای اصلی

### سرور (`server/`)

| فایل | نقش |
| --- | --- |
| `main.py` | اندپوینتهای OpenAI، جریان SSE، داشبورد HTML، وبسوکت افزونه |
| `admin.py` | پنل `/admin` و API جیسون آن |
| `webui.py` + `assets/` | پوستهٔ پنل و فایل‌های `panel.css` / `panel.js` |
| `history.py` | تاریخچهٔ محدود درون‌حافظه‌ای درخواست‌ها |
| `auth.py` | بررسی مشترک `Authorization` برای `/v1` و `/admin/api` |
| `config.py` | خواندن تنظیمات از محیط یا فایل `.env` |
| `models.py` | مدلهای Pydantic برای OpenAI و پروتکل مرورگر |
| `prompt_builder.py` | تبدیل `messages[]` به یک متن برچسبدار |
| `sanitizer.py` | شناسایی/بیاثر کردن دستورهای مخرب در پاسخ سایت |
| `websocket_manager.py` | اتصال واحد مرورگر، صف ترتیبی، آمار و timeout |
| `mock_browser.py` | مرورگر جعلی برای تست و دمو بدون Chrome/Firefox |

### افزونه (`extensions/`)

```
extensions/
├── shared/              ← تنها جایی که کد ویرایش میشود (مشترک بین دو مرورگر)
│   ├── config.js        سلکتورها، آستانهها، آدرس سرور  ← از اینجا شروع کنید
│   ├── content.js       مالک وبسوکت؛ تایپ، کلیک Send، خواندن پاسخ
│   ├── inject.js        هوک دنیای صفحه برای رصد استریم سایت (فقط خواندن)
│   ├── background.js    اجارهٔ اتصال به یک تب، keepalive، تزریق مجدد اسکریپت
│   ├── settings.js      مدل تنظیمات/بازنویسی مشترک (اعتبارسنجی، ذخیره، خروجی)
│   ├── i18n.js          رشته‌های انگلیسی/فارسی + اعمال‌کنندهٔ data-i18n
│   ├── popup.html/js    وضعیت، «تست سریع»، «Diagnose DOM»، تنظیمات، لغو
│   ├── options.html/js  صفحهٔ کامل تنظیمات افزونه
│   └── icons/           آیکونهای تولیدشده
├── chrome/manifest.json    service worker · world:MAIN · کروم ۱۱۱+
└── firefox/manifest.json   event page · gecko id · مجوزهای opt-in · فایرفاکس ۱۲۸+
```

خروجی بیلد در `dist/chrome` و `dist/firefox` ساخته میشود؛ همانها را در مرورگر
لود میکنید. کد مشترک در هر دو بسته بایتبهبایت یکسان است و فقط `manifest.json`
تفاوت دارد.

## امکانات کلیدی

- **سازگاری کامل OpenAI**: `stream: true/false`، مدلهای `arena-agent` و
  `arena-agent-direct`، بدنهٔ خطای استاندارد، `usage` تخمینی.
- **صف تکدرخواستی**: از تداخل و پاسخهای قاطی جلوگیری میکند؛ عمق صف در
  `/v1/bridge/status` دیده میشود.
- **ایمنسازی پاسخ (Sanitizer)**: پاسخ سایت «ورودی غیرقابل اعتماد» است؛ دستورهای
  مخرب (`rm -rf /`، `curl … | bash`، reverse shell، خواندن کلید SSH/AWS،
  `base64 | sh` و…) پیشفرض با `[BLOCKED BY ARENA-AGENT-BRIDGE: rule]` جایگزین
  میشوند و همهٔ موارد در `x_bridge.sanitize_findings` گزارش میشوند.
  سه حالت: `redact` (پیشفرض)، `detect` (فقط گزارش)، `off`.
- **تشخیص پایان پاسخ** با سه مسیر مستقل: پایدار شدن متن (۳ ثانیه)، سکوت استریم
  (`SSE_IDLE_MS`)، و فریم `done`؛ بهعلاوهٔ backstop با تایمر. اگر هوک صفحه توسط CSP
  مسدود شود، حالت **DOM-only** فعال میشود (کندتر، ولی درست).
- **خطاهای صریح و قابل ترجمه** به کدهای HTTP و پیامهای راهنما.
- **داشبورد وضعیت** روی `/`، آمار روی `/v1/bridge/status`، سلامت روی `/healthz` و
  آمادگی روی `/readyz`.
- **بدون ذخیرهٔ اعتبارنامه**: نه کوکی، نه توکن؛ فقط همان نشست مرورگر خودتان.
- **مجوزهای حداقلی افزونه**: `storage`، `alarms`، `scripting` و فقط سه میزبان
  (arena.ai + لوکالهاستها). بدون `cookies`، بدون `webRequest`، بدون `<all_urls>`،
  بدون `eval`.

## نصب در پنج دقیقه

### پیشنیازها

- Python 3.10 یا بالاتر
- Chrome/Edge نسخهٔ ۱۱۱+ یا Firefox نسخهٔ ۱۲۸+
- لینوکس، مک یا ویندوز

### گام ۱ — راهاندازی سرور

```bash
git clone https://github.com/startify2647/ArenaAgentBridge.git arena-agent-bridge
cd arena-agent-bridge

./scripts/run.sh                 # ساخت .venv، نصب وابستگیها، اجرا روی 127.0.0.1:8000
```

یا بهصورت دستی:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r server/requirements.txt
python -m server
cp .env.example .env             # اختیاری: تنظیم timeout، پورت، ایمنساز و…
```

بررسی: <http://127.0.0.1:8000/> یا

```bash
curl -s http://127.0.0.1:8000/v1/bridge/status | python -m json.tool
```

### گام ۲ — ساخت و نصب افزونه

```bash
python scripts/build-extensions.py     # خروجی در dist/chrome و dist/firefox
```

| مرورگر | روش نصب |
| --- | --- |
| **کروم / اج / بریو** | `chrome://extensions` → فعالکردن *Developer mode* → **Load unpacked** → پوشهٔ `dist/chrome` |
| **فایرفاکس ۱۲۸+** | `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → فایل `dist/firefox/manifest.json` → سپس در پاپآپ **Grant permissions** را بزنید |

سپس <https://arena.ai/agent> را باز کنید و مطمئن شوید **وارد حساب شدهاید**. نشان
کوچک گوشهٔ پایین-راست صفحه باید `bridge: connected` باشد؛ پاپآپ افزونه وضعیت سرور،
تبِ متصل و دکمهٔ **Diagnose DOM** را نشان میدهد.

> در فایرفاکس مجوزهای میزبان **opt-in** هستند؛ تا زمانی که مجوز ندهید خطای
> `browser_offline` میگیرید. افزونههای موقت با بستن مرورگر حذف میشوند؛ گزینههای
> نصب دائمی در [docs/FIREFOX.fa.md](docs/FIREFOX.fa.md) آمده است.

### گام ۳ — اولین درخواست

```bash
curl -s http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer sk-arena' \
  -d '{
        "model": "arena-agent",
        "messages": [{"role": "user", "content": "فقط این را جواب بده: bridge ok"}]
      }' | python -m json.tool
```

نمونههای بیشتر (جریان، چندنوبتی، خطاها): [`tests/curl_examples.sh`](tests/curl_examples.sh).

### دموی بدون مرورگر (۳۰ ثانیه)

```bash
./scripts/demo.sh        # یا: make demo
```

سرور را با `AAB_MOCK_BROWSER=1` بالا میآورد و `/v1/models`، یک درخواست معمولی، یک
درخواست جریانی و وضعیت پل را نشان میدهد — بدون نیاز به کروم یا فایرفاکس.

## رابط کاربری وب و پنل مدیریت

دو رابط همراه پروژه می‌آید؛ هر دو فقط محلی‌اند، مرحلهٔ build جداگانه و فایل
بیرونی (CDN) ندارند:

```bash
./scripts/run.sh                                  # اجرای سرور
# سپس در مرورگر: http://127.0.0.1:8000/admin      (یا / · /ui · /panel)
```

* **پنل مدیریت** (`/admin`): داشبورد زنده (مرورگر، صف، تأخیر، درخواست در جریان،
  خطاهای اخیر)، **Playground** برای اجرای واقعی پرامپت از ابتدا تا انتهای زنجیره،
  **تاریخچهٔ درخواست‌ها** (محدود، در حافظه، فیلترپذیر، قابل خروجی گرفتن)، کنترل
  مرورگر (ping / تشخیص DOM / لغو / قطع اتصال)، بازرسی بدون‌اجرای ایمن‌ساز، فرم
  **تنظیمات** زمان اجرا (اعمال بدون ری‌استارت و کپی `.env` معادل)، فهرست
  خودآزمایی و قطعه‌کدهای آمادهٔ اتصال. دوزبانه (**فارسی/English**) با پشتیبانی
  RTL، پوستهٔ تاریک/روشن و به‌روزرسانی خودکار قابل توقف. اگر
  `AAB_REQUIRE_API_KEY=1` باشد، پنل هم همان کلید را می‌خواهد.
* **رابط افزونه**: پاپ‌آپ نوار ابزار (وضعیت، **تست سریع** از داخل مرورگر،
  تشخیص DOM، تنظیمات، اتصال مجدد/لغو) و **صفحهٔ تنظیمات کامل** (آدرس سرور، کلید
  API، آستانه‌ها، capture، ورود/خروجی گرفتن و بازنشانی، مجوزهای فایرفاکس).
  مقادیر اعتبارسنجی می‌شوند، در `chrome.storage.local` می‌مانند و اسکریپت محتوا
  بی‌درنگ اعمالشان می‌کند.

مرجع کامل: [`docs/WEBUI.fa.md`](docs/WEBUI.fa.md) · [English](docs/WEBUI.md).

## اتصال Hermes / OpenClaw

| تنظیم | مقدار |
| --- | --- |
| Base URL | `http://127.0.0.1:8000/v1` |
| حالت سازگاری | **Chat Completions** (نه Responses API) |
| API Key | هر مقدار دلخواه، مثلاً `sk-arena` |
| Model ID | `arena-agent` (یا `arena-agent-direct`) |
| Streaming | پشتیبانی میشود |

نکتهها:

- **Function/Tool calling پشتیبانی نمیشود.** اگر ابزارتان اصرار دارد، آن قابلیت را
  برای این provider خاموش کنید یا بهصورت متن ساده استفاده کنید.
- همزمانی را روی ۱ بگذارید؛ درخواستهای اضافه در صف میمانند.
- برای کارهای طولانی، `AAB_REQUEST_TIMEOUT=900` را در `.env` بگذارید.

دستورهای کامل برای هر کلاینت: [docs/HERMES_OPENCLAW.fa.md](docs/HERMES_OPENCLAW.fa.md).

## تنظیمات

### سرور — فایل `.env` (نمونه در [`.env.example`](.env.example))

| متغیر | پیشفرض | کار |
| --- | --- | --- |
| `AAB_HOST` / `AAB_PORT` | `127.0.0.1` / `8000` | محل گوشدادن API — روی لوکالهاست نگه دارید |
| `AAB_REQUEST_TIMEOUT` | `300` | چند ثانیه برای پاسخ صفحه صبر کند |
| `AAB_QUEUE_MAX_SIZE` | `64` | تعداد درخواست در صف؛ بیشتر از آن خطای ۴۲۹ |
| `AAB_DEFAULT_MODE` | `agent` | `agent` = مقدمه + متن، `direct` = فقط متن |
| `AAB_SANITIZE_MODE` | `redact` | `off` / `detect` / `redact` |
| `AAB_PATTERNS_FILE` | – | فایل JSON با قوانین دلخواه ایمنساز |
| `AAB_REQUIRE_API_KEY` | `0` | با `1` و `AAB_API_KEY` احراز هویت اجباری میشود |
| `AAB_STREAM_CHUNK_CHARS` / `AAB_STREAM_CHUNK_DELAY_MS` | `32` / `12` | ریتم پخش جریان SSE |
| `AAB_MOCK_BROWSER` | `0` | `1` = پاسخ ساختگی بدون مرورگر (فقط تست) |
| `AAB_PANEL_ENABLED` | `1` | پنل مدیریت روی `/admin` (و `/`، `/ui`، `/panel`) |
| `AAB_PANEL_REFRESH_MS` | `2000` | فاصلهٔ به‌روزرسانی خودکار پنل |
| `AAB_HISTORY_SIZE` | `200` | تعداد درخواست‌های نگه‌داشته‌شده در تاریخچهٔ پنل (`0` = خاموش) |
| `AAB_LOG_LEVEL` / `AAB_LOG_JSON` | `INFO` / `0` | سطح و قالب لاگ |

### افزونه — `extensions/shared/config.js`

همهٔ چیزهای وابسته به سایت اینجاست: سلکتورها، آستانهها، پیشوندهای استریم و پرچمهای
اشکالزدایی. حتی میتوانید در کنسول صفحه مقدارها را زنده تغییر دهید:

```js
__AAB_CONFIG__.selectors.input.unshift('textarea.my-new-class');
__AAB__.diagnose();
```

| کلید | پیشفرض | معنا |
| --- | --- | --- |
| `INPUT_WAIT_MS` | `20000` | چقدر برای پیداشدن کادر متن صبر کند |
| `IDLE_STALL_MS` | `45000` | نه صفحه و نه استریم سایت این مدت تغییر نکند ⇐ خطای `site_idle` به‌جای معطل ماندن |
| `PARTIAL_ON_TIMEOUT` | `true` | در پایان مهلت، پاسخ جزئی تحویل داده شود نه timeout خالی |
| `AUTO_KEEP_WORKING` | `true` | در حالت agent به نظرسنجی پایان پاسخ («Keep working») پاسخ می‌دهد تا پرامپت بعدی ارسال شود |
| `KEEP_WORKING_WAIT_MS` | `4000` | پس از آرام شدن پاسخ، این مدت برای پیدا کردن نظرسنجی صبر می‌کند |
| `HEARTBEAT_MIN_MS` | `5000` | ضربان مبتنی بر فعالیت: زنده نگه داشتن سوکت در تب پس‌زمینه |
| `STABLE_MS` | `3000` | متن این مدت ثابت بماند ⇐ پاسخ تمام شده |
| `SSE_IDLE_MS` | `1200` | استریم ساکت + متن ثابت ⇐ پایان سریع |
| `STALL_MS` | `25000` | رشد نکند ولی دکمهٔ Stop باشد ⇐ پاسخ ناقص برگردد |
| `NO_OUTPUT_MS` | `60000` | هیچ خروجیای نیاید ⇐ خطای `no_output` |
| `MAX_WAIT_MS` | `300000` | سقف سخت هر درخواست |
| `RESET_BEFORE_REQUEST` | `false` | قبل از هر درخواست «New chat» بزند |
| `capture.INJECTION` | `manifest` | روش تزریق هوک (`manifest` یا `runtime`) |
| `SHOW_BADGE` | `true` | نمایش نشان وضعیت روی صفحه |

## عیبیابی سریع

```bash
curl -s http://127.0.0.1:8000/readyz            # مرورگر وصل است؟
curl -s http://127.0.0.1:8000/v1/bridge/status  # وضعیت کامل
```

| نشانه | راهحل |
| --- | --- |
| `browser_offline` | آیا `dist/<مرورگر>` را لود کردهاید (نه سورس را)؟ صفحه باز و لاگین است؟ در فایرفاکس مجوز دادهاید؟ |
| نشان `disconnected` | سرور بالاست؟ تب قبل از نصب افزونه باز نشده باشد (تب را رفرش یا در پاپآپ *Reconnect* بزنید) |
| `dom_changed` | پاپآپ → **Diagnose DOM**؛ سلکتور جدید را به `extensions/shared/config.js` اضافه و دوباره بیلد کنید |
| `captcha_required` | کپچا را دستی در همان تب حل کنید؛ پل هیچوقت کپچا را دور نمیزند |
| پاسخ ناقص یا چسبیدن نوبت قبل | `STABLE_MS` و `SSE_IDLE_MS` و سلکتور پیام assistant را تنظیم کنید |
| خطای `site_idle` | تب در میانهٔ درخواست از تغییر افتاده (فریز/تعلیق/پایان نشست). اگر پرامپت‌های شما طبیعتاً صفحه را بی‌تغییر نگه می‌دارند `IDLE_STALL_MS` را بالا ببرید |
| هیچ‌چیز جز *Diagnose DOM* کار نمی‌کند | مسیر خودکارسازی جعبهٔ ورودی یا دکمهٔ ارسال را پیدا نکرده؛ *Diagnose DOM* همهٔ سلکتورها را نشان می‌دهد و ردیف «آخرین کنش» در پاپ‌آپ می‌گوید پل آخرین کارش چه بوده |
| کندی زیاد | پل تکدرخواستی است؛ تب را در پنجرهٔ جدا نگه دارید و برای پرامپتهای کوتاه از حالت `direct` استفاده کنید |

فهرست کامل: [docs/TROUBLESHOOTING.fa.md](docs/TROUBLESHOOTING.fa.md).

## امنیت

- **فقط لوکالهاست.** پیشفرض `127.0.0.1` است و CORS فقط مبدأ افزونه، `localhost`
  و خود سایت را میپذیرد. آن را روی شبکه باز نکنید — چون بهطور پیشفرض هر Bearer
  توکنی پذیرفته میشود (مرز امنیتی «فقط همین دستگاه» است).
- **بدون اعتبارنامه.** هیچ کوکی، توکن یا پروفایلی خوانده، ذخیره یا ارسال نمیشود.
  افزونه فقط از نشست موجود مرورگر شما استفاده میکند و سرور پرامپتها را تنها در
  حافظه نگه میدارد.
- **ورودی غیرقابل اعتماد.** پاسخ سایت ممکن است دستور مخرب یا prompt injection
  داشته باشد؛ ایمنساز پیشفرض آنها را بیاثر و گزارش میکند.
- **بدون دور زدن کپچا و بدون پنهانکاری.** هیچ جعل اثر انگشت یا مخفیکردن حالت
  خودکارسازی وجود ندارد.
- **مجوزهای حداقلی.** `storage`، `alarms`، `scripting` و سه میزبان مشخص؛ بدون
  `cookies`، بدون `webRequest`، بدون `<all_urls>`، بدون `eval`، بدون تحلیل آماری.
- **احراز هویت اختیاری.** با `AAB_REQUIRE_API_KEY=1` و `AAB_API_KEY=…` میتوانید یک
  توکن واقعی اجباری کنید (مفید روی دستگاه مشترک).

## محدودیتها

- **هر بار یک درخواست.** سایت ترتیبی است؛ بقیه در صف میمانند (در `queue_depth` دیده میشود).
- **بدون Function calling** و بدون احترام به `temperature`/`top_p`/`max_tokens`/
  `stop`؛ `usage` تخمینی است.
- **جریان شبیهسازیشده است**: پاسخ کامل گرفته و بعد بهصورت تکهتکه پخش میشود
  (`x_bridge.streamed = true`).
- **وابستگی به DOM**: تغییر ظاهر سایت سلکتورها را میشکند؛ خطا صریح است (`dom_changed`).
- **تبهای پسزمینه کند میشوند** (هر دو مرورگر)؛ تب را در پنجرهٔ جدا نگه دارید.
- **حافظهٔ گفتگو در خود صفحه است**؛ نشستهای طولانی ممکن است افت کنند
  (`RESET_BEFORE_REQUEST = true` برای شروع تمیز در هر درخواست).
- **ورودی تصویر/صدا حذف میشود** (`[image omitted by bridge]`) و پیوست/ابزارهای سایت
  قابل راهاندازی نیستند.

## پرسشهای متداول

**آیا از API رسمی استفاده میکند؟** نه. کاملاً از رابط وب و نشست خودتان.
**آیا کپچا را دور میزند؟** نه؛ اگر کپچا ظاهر شود درخواست با `captcha_required`
شکست میخورد و از شما میخواهد دستی حل کنید.
**آیا کوکی یا توکن ذخیره میشود؟** نه. هیچچیز از مرورگر خوانده یا جایی فرستاده نمیشود.
**چند درخواست همزمان؟** یکی؛ بقیه در صف (قابل مشاهده در `/v1/bridge/status`).
**مقدار API Key؟** هر چیزی مثل `sk-arena` کافی است، مگر `AAB_REQUIRE_API_KEY=1`.
**چرا پاسخ طول میکشد؟** چون سرعت واقعی خود سایت است، بهعلاوهٔ زمان انتظار در صف.
**آیا میشود روی سرور راه دور اجرا کرد؟** نه؛ پل باید روی همان دستگاهی باشد که مرورگر
لاگینشده در آن است.

## هشدار حقوقی و ایمنی

- خودکارسازی Arena.ai به این شکل **احتمالاً ناقض شرایط استفادهٔ آن سایت** است و ممکن
  است حساب شما محدود، معلق یا مسدود شود. این ریسک با خودتان است.
- این پروژه هیچ پیوال، احراز هویت، محدودیت نرخ یا کپچایی را دور نمیزند؛ فقط از
  نشست موجود شما روی دستگاه خودتان استفاده میکند.
- فقط برای استفادهٔ شخصی و آزمایشی. دسترسی را نفروشید، آن را بهعنوان سرویس برای
  دیگران اجرا نکنید و آن را به حسابهایی که مالکشان نیستید وصل نکنید.
- محدودیتهای سایت را رعایت کنید: یک تب، یک درخواست همزمان، timeout منطقی. اگر
  حجم بالا لازم دارید از API رسمی استفاده کنید.
- پاسخها محتوای غیرقابل اعتماد وب هستند. اگر فریمورک ایجنت شما دستور شل اجرا میکند،
  ایمنساز را روشن (یا سختگیرانهتر) نگه دارید و هرگز اجازه ندهید ایجنت کد یک صفحهٔ
  وب را بدون نظارت اجرا کند.
